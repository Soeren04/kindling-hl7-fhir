# Changesets

Every pull request that changes the published package (`packages/hl7-to-fhir`) adds a changeset here with
`pnpm changeset`; CI enforces it. Changes that need no release note, such as tooling, use
`pnpm changeset --empty`. See [CONTRIBUTING.md](../CONTRIBUTING.md#changesets) and [Changesets](https://github.com/changesets/changesets).
